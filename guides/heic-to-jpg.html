HEIC to JPG Converter: Making iPhone Photos Easier to Open

JPG or PNG

This HEIC to JPG converter re-encodes one or more .heic photos as JPEG or PNG. Choose JPEG quality from 10 to 100; the default is 90. One converted photo downloads directly. A batch is delivered as converted-images.zip. The converted files are convenient sharing copies, but they should not replace originals when metadata or HEIC-specific features matter.

Open HEIC Converter

Why convert HEIC files?

HEIC is an efficient image container commonly created by Apple devices. It can store high-quality photographs using less space than a comparable JPEG, but support varies among upload forms, older applications, printers, and non-Apple workflows. Converting creates a separate, more widely supported copy without changing the original file.

  • Forms and portals: create a JPG when an upload field rejects HEIC.
  • Documents and presentations: use a format that common office software can place more reliably.
  • Photo batches: convert several images and receive one ZIP instead of many download prompts.
  • Screenshots or text-heavy images: choose PNG when preserving exact pixel edges matters more than file size.

JPG or PNG: choose for the job

Choose JPG for photographs

JPEG uses lossy compression, so it can make natural photographs easier to share. Quality 90 is the default. Lower settings usually create smaller files but can introduce blocking, ringing, and softened detail.

Choose PNG for exact pixels

PNG is lossless and is often better for screenshots, text, and hard edges. A PNG made from a photograph can be much larger than both the HEIC source and a JPEG copy. The JPEG quality slider is not a PNG size control.

Keep the HEIC original. JPEG loss is permanent, and neither JPG nor PNG can represent every HEIC/HEIF feature. Reconvert from the original when you need a different quality or format.

How to convert HEIC to JPG or PNG

1

Add genuine .heic files

Select one file or a batch. The current filter accepts the .heic extension, not .heif.

2

Choose output settings

Pick JPEG or PNG. For JPEG, start at quality 90 and reduce it only when the result must be smaller.

3

Download and inspect

A single image downloads directly. Extract the ZIP for a batch, then check orientation, detail, color, and filenames.

What happens in the browser

  1. 1. Load: heic2any 0.0.4 is downloaded from a third-party CDN when required.
  2. 2. Decode: each selected file is passed to heic2any with the requested MIME type and quality value.
  3. 3. Name: the final .heic suffix is replaced with .jpg or .png.
  4. 4. Package: one Blob downloads directly. JSZip 3.10.1 stores several converted Blobs in converted-images.zip.

The loop processes files sequentially, not in parallel. Large batches therefore take longer and require more browser memory. File contents are processed in browser memory and are not sent to WeConvertFiles for conversion.

Important limitations

  • Only .heic names are accepted: the current filter rejects .heif even though HEIC is part of the HEIF family.
  • First image only: if heic2any returns an array for a multi-image container, the implementation keeps the first Blob and does not export the remaining images.
  • Features may be lost: do not expect depth data, auxiliary images, editing history, or Live Photo motion to appear in a still JPG or PNG.
  • Metadata is not guaranteed: preserve the HEIC source if capture time, GPS, camera settings, or other metadata matters.
  • No editing: the tool does not rotate, crop, resize, or correct color.
  • Memory is the practical limit: the code sets no file-count or file-size maximum, but a large batch can exhaust a low-memory browser.
  • Duplicate names need care: files with identical base names produce identical output names and can conflict inside one ZIP. Rename them uniquely before converting.

Privacy and data handling

Photo contents are processed in browser memory and are not sent to WeConvertFiles for conversion. heic2any and JSZip are downloaded from third-party CDNs when needed, so the workflow is not described as fully offline.

Zoho PageSense may collect consented site-usage data such as visits, clicks, scrolling, referrer, device information, and conversion events. PageSense is not given the contents of the selected photos.

Troubleshooting

The file is rejected

Check that its name ends in .heic. Renaming another format does not convert its underlying data, and .heif is not accepted by the current filter.

Conversion is slow or stalls

HEIC decoding is demanding and files run one after another. Close heavy tabs and try a smaller batch.

The JPG looks soft or blocky

Return to the HEIC original and choose a higher JPEG quality. Do not repeatedly resave an already compressed JPG.

The PNG is unexpectedly large

PNG preserves pixels losslessly and is inefficient for many photographs. Use JPEG when a smaller photographic copy is the priority.

The ZIP contains fewer files than expected

Confirm every source appeared in the selected-file list and that names were unique. Convert problematic files individually to identify the one that fails.

Frequently asked questions

Will JPG conversion reduce quality?

Yes. JPEG is lossy, although the difference may be difficult to notice at quality 90 on an ordinary photo. Lower values discard more detail.

Does PNG preserve the original HEIC perfectly?

PNG preserves the decoded pixels losslessly, but it does not preserve every HEIC container feature or guarantee the original metadata.

What happens to a Live Photo?

Treat the result as a still image. Keep the original HEIC and its paired video if motion matters.

Is there a fixed batch limit?

The code does not impose one. Available memory and processing time are the real constraints, so smaller batches are safer on phones and older computers.

Why does quality not change PNG?

The control is labelled JPEG only. PNG uses lossless compression and does not offer the same quality-versus-size setting.
