Frequently Asked Questions

Are my SQL queries executed or stored on a database server?

No! Our SQL Formatter only formats and aligns text syntax using browser JavaScript memory. Queries are never executed or uploaded to any database or server.

Which SQL dialects are supported?

The tool supports Standard SQL, MySQL, PostgreSQL, and T-SQL (SQL Server) dialects with keyword casing and custom indentation settings.
